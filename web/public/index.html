API

  • GET /api/overview latest ratios and coverage per machine
  • GET /api/series?machine=&benchmark=&metric=&profile= time series per configuration
  • GET /api/commit/<sha> every measurement of one commit with deltas to its parent
  • GET /api/compare?machine=&a=&b= two commits side by side
  • GET /api/coverage?machine= which commits are measured, inherited, unavailable or pending
  • GET /api/commits, GET /api/machines, GET /api/experiments
