How to read this

Every machine measures every configuration itself, so ratios are comparable across machines even though absolute times are not. Commits that leave the compiler untouched inherit their neighbour's result and count toward coverage. The timeline shows how each ratio moved over the commit history, the coverage page shows which commits have been measured, and every number links to its commit.
